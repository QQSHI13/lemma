# Lemma — Linking System Design

> **Status:** Design document (P2 — infrastructure, no API costs)
> **Problem:** Individual `.md` files are islands. A math wiki needs dense cross-references.

---

## The Core Insight

Math is a **graph**, not a folder. Every concept connects to:
- **Prerequisites** (what you must know first)
- **Generalizations** (broader concepts)
- **Specializations** (specific cases)
- **Applications** (where this is used)
- **Related** (siblings, analogs, duals)

If humans have to maintain all these links manually, the wiki dies at 100 pages. The system must **generate and validate links automatically** from `concepts.json`.

---

## 1. Link Syntax (Wikilinks)

Use `[[concept-id]]` everywhere. The pipeline resolves it.

```markdown
# Eigenvalue

## Definition

A scalar λ is an [[eigenvalue]] of a [[linear-map]] T: V → V
if there exists a non-zero [[vector]] v such that T(v) = λv.

## Examples

### Example 1: 2×2 Matrix
Consider A = [[3,1],[0,2]]. The [[characteristic-polynomial]]
is (3-λ)(2-λ) = 0, so the [[eigenvalue|eigenvalues]] are 3 and 2.

## Related

<!-- AUTO-GENERATED by pipeline — do not edit -->
- **Prerequisites**: [[linear-map]], [[vector-space]], [[field]], [[polynomial]]
- **Used by**: [[diagonalization]], [[spectral-theorem]], [[principal-component-analysis]]
- **Specializations**: [[eigenvector]]
- **See also**: [[characteristic-polynomial]], [[determinant]]
```

### Link Types

| Syntax | Renders As | Example |
|--------|-----------|---------|
| `[[eigenvalue]]` | [Eigenvalue](eigenvalue.md) | Standard link |
| `[[eigenvalue\|eigenvalues]]` | [eigenvalues](eigenvalue.md) | Custom display text |
| `[[#formal-statement]]` | [Formal Statement](#formal-statement) | Same-page anchor |
| `[[eigenvalue#examples]]` | [Eigenvalue § Examples](eigenvalue.md#examples) | Cross-page anchor |

## 3. Auto-Generated Related Section

The `## Related` section is **generated by the pipeline**, not written by hand.

```python
def generate_related(concept_id: str, concepts: dict) -> str:
    """Generate the Related section from the dependency graph."""
    c = concepts[concept_id]
    lines = ["<!-- AUTO-GENERATED by lemma_pipeline.py — do not edit manually -->"]
    
    # Prerequisites (upstream)
    if c.get("prerequisites"):
        prereqs = [f"[[{p}]]" for p in c["prerequisites"] if p in concepts]
        lines.append(f"- **Prerequisites**: {', '.join(prereqs)}")
    
    # Unlocks (downstream — what this enables)
    if c.get("unlocks"):
        unlocks = [f"[[{u}]]" for u in c["unlocks"] if u in concepts]
        lines.append(f"- **Unlocks**: {', '.join(unlocks)}")
    
    # Bidirectional: who depends on me?
    used_by = [k for k, v in concepts.items() if concept_id in v.get("prerequisites", [])]
    if used_by:
        lines.append(f"- **Used by**: {', '.join(f'[[{u}]]' for u in used_by)}")
    
    # Related (siblings, analogs)
    if c.get("related"):
        related = [f"[[{r}]]" for r in c["related"] if r in concepts]
        lines.append(f"- **See also**: {', '.join(related)}")
    
    # Generalization / Specialization
    if c.get("generalizes"):
        lines.append(f"- **Generalization**: [[{c['generalizes']}]]")
    if c.get("specializes"):
        specs = [f"[[{s}]]" for s in c["specializes"] if s in concepts]
        lines.append(f"- **Specializations**: {', '.join(specs)}")
    
    return "\n".join(lines)
```

**Result in the built page:**

```markdown
## Related

<!-- AUTO-GENERATED by lemma_pipeline.py — do not edit manually -->
- **Prerequisites**: [[linear-map]], [[vector-space]], [[field]], [[polynomial]]
- **Unlocks**: [[diagonalization]], [[spectral-theorem]], [[principal-component-analysis]]
- **Used by**: (none yet — this concept is new)
- **See also**: [[eigenvector]], [[characteristic-polynomial]], [[determinant]]
- **Specializations**: [[eigenvector]]
```

## 4. Link Validation (CI Gate)

The pipeline checks every link at build time:

```python
def validate_links(concepts: dict, docs_dir: Path) -> List[str]:
    """Return list of link violations."""
    violations = []
    
    for concept_id, concept in concepts.items():
        page_path = docs_dir / concept["area"] / f"{concept_id}.md"
        if not page_path.exists():
            continue
        
        content = page_path.read_text()
        
        # Extract all [[wikilinks]]
        wikilinks = re.findall(r'\[\[([^\]|]+)(?:\|[^\]]+)?\]\]', content)
        
        # Check each link resolves
        for link in wikilinks:
            link_id = link.split('#')[0]  # Remove anchor
            if link_id not in concepts:
                violations.append(f"{concept_id}: Broken wikilink [[{link_id}]]")
        
        # Check prerequisite links actually appear in content
        for prereq in concept.get("prerequisites", []):
            if f"[[{prereq}]]" not in content:
                violations.append(
                    f"{concept_id}: Prerequisite [[{prereq}]] not linked in content"
                )
        
        # Check for orphan pages (published but no incoming links)
        if concept["status"] == "published":
            incoming = [k for k, v in concepts.items() if concept_id in v.get("prerequisites", [])]
            if not incoming and concept_id != "proposition":  # Root concept exception
                violations.append(f"{concept_id}: Published but no incoming links (orphan)")
    
    return violations
```

**CI fails if any violations exist.**

## 5. Missing Link Detection

The pipeline suggests links you forgot to add:

```python
def suggest_links(concept_id: str, content: str, concepts: dict) -> List[str]:
    """Suggest concepts mentioned but not linked."""
    suggestions = []
    
    for other_id, other in concepts.items():
        if other_id == concept_id:
            continue
        
        # Count mentions of the concept name
        name_pattern = re.compile(r'\b' + re.escape(other["name"]) + r'\b', re.I)
        mentions = len(name_pattern.findall(content))
        
        # Check if already linked
        already_linked = f"[[{other_id}]]" in content
        
        if mentions >= 2 and not already_linked:
            suggestions.append(
                f"Mentioned {mentions}x: [[{other_id}]] ({other['name']})"
            )
    
    return suggestions
```

**Example output:**
```
Page: eigenvalue.md
Suggestions:
  Mentioned 5x: [[vector-space]] (Vector Space) — consider linking
  Mentioned 3x: [[matrix]] (Matrix) — consider linking
  Mentioned 2x: [[determinant]] (Determinant) — consider linking
```

## 8. Link Types in Practice

| Relationship | Direction | Example |
|-------------|-----------|---------|
| **Prerequisite** | A → B (A needs B) | eigenvalue → linear-map |
| **Unlocks** | A → B (A enables B) | eigenvalue → diagonalization |
| **Generalizes** | A ← B (B is more general) | linear-map ← eigenvalue |
| **Specializes** | A → B (B is more specific) | eigenvalue → eigenvector |
| **Related** | A ↔ B (siblings/analogs) | eigenvalue ↔ determinant |
| **Uses** | A → B (A applies B) | diagonalization → eigenvalue |

## 9. Implementation Order

1. **Add link fields to concepts.json** (`prerequisites`, `unlocks`, `related`, `generalizes`, `specializes`)
2. **Implement wikilink parser** in pipeline (`[[concept-id]]`)
3. **Auto-generate Related sections** from graph
4. **Build link validator** (CI gate)
5. **Build missing-link suggester**
6. **Build bidirectional index**
7. **Add visual graph view** (D3.js force-directed graph)

## 10. What This Enables

| Feature | How |
|--------|-----|
| **Browse by dependency** | Click "Prerequisites" to go backward, "Unlocks" to go forward |
| **Learning paths** | "I want to learn linear algebra" → system finds path from foundations to eigenvalue |
| **Auto-toc per area** | Generated from graph, not hand-maintained |
| **Regression testing** | Change a definition → see all 47 pages that depend on it |
| **Difficulty estimate** | Longest path from foundations = conceptual depth |
| **Coverage gaps** | "34 concepts reference X but it has no page" |

## Summary: File vs Graph

| | **Folder of Files** | **Linked Graph (Lemma)** |
|---|-------------------|------------------------|
| Navigate | Search or index | Follow links |
| Discover | Read TOC | Browse "See also" |
| Validate | None | CI checks all links |
| Maintain | Edit every page manually | Edit graph, regenerate links |
| Scale | Breaks at 50 pages | Works at 10,000 pages |

**The graph IS the wiki.** The markdown files are just views into it.
