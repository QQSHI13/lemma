# Lemma — Simple Wiki Design (GitHub Pages Only)

> **Constraints:** No server. Static site only. GitHub Pages + DocsForge.
> **Goal:** A wiki that's easy to browse, read, and navigate — like Wikipedia but for math.

---

## What We're NOT Building

❌ Login/progress tracking  
❌ Quizzes or paths  
❌ Adaptive learning  
❌ Real-time collaboration  
❌ Server-side anything  

**Why:** GitHub Pages is static HTML only.

---

## What We ARE Building

✅ Clean, readable pages  
✅ Search (client-side)  
✅ Cross-links everywhere  
✅ Category browsing  
✅ Simple visual graph (static SVG)  
✅ Mobile-friendly

## 5. Cross-Linking (Wikilinks)

In markdown, write:
```markdown
A scalar λ is an [[eigenvalue]] of a [[linear-map]].
```

Pipeline converts to:
```html
A scalar λ is an <a href="/algebra/eigenvalue/">eigenvalue</a>
of a <a href="/algebra/linear-map/">linear map</a>.
```

**If link target doesn't exist yet:** Renders as gray with tooltip:
```html
<a href="#" class="missing-link" title="Page not written yet">
  spectral-theorem
</a>
```

## 11. The Pipeline (Simplified)

```
concepts.json
    │
    ├──► docs/*.md (pages with wikilinks)
    │
    ├──► search-index.json (for Pagefind)
    │
    ├──► graph.svg (Graphviz)
    │
    ├──► index.html (homepage)
    │
    └──► area-*.html (area index pages)

DocsForge builds everything to site/
GitHub Pages deploys site/
```

**All generated at build time. No runtime server.**

---

## 12. Example: Full Build Flow

```bash
# 1. Edit a spec
vim specs/eigenvalue.yaml

# 2. Generate page
python scripts/generate_page.py specs/eigenvalue.yaml
# → creates docs/algebra/eigenvalue.md

# 3. Commit
git add docs/algebra/eigenvalue.md
git commit -m "content: eigenvalue"
git push

# 4. CI runs
.github/workflows/build.yml:
  - Parse concepts.json
  - Generate related sections
  - Convert wikilinks
  - Build search index
  - Generate graph SVG
  - Build site with DocsForge
  - Deploy to GitHub Pages

# 5. Live at https://qqshi13.github.io/lemma/algebra/eigenvalue/
```
