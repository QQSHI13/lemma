# Lemma

A personal mathematics wiki built with [DocsForge](https://github.com/QQSHI13/docsforge).

## Setup

```bash
pip install docsforge
docsforge serve
```

## Build

```bash
docsforge build
```

## Features

- **Math rendering** with KaTeX
- **TikZ diagrams** compiled to SVG
- **Full-text search**
- **Dark mode**
- **GitHub Pages** deployment
