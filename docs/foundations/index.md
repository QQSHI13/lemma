# Foundations

The building blocks of mathematics.

## Logic

The study of valid reasoning.

- [Proposition](proposition.md) — A statement that is either true or false
- [Truth Table](truth-table.md) — Systematic listing of all truth values
- [Logical Connective](logical-connective.md) — AND, OR, NOT, IMPLIES
- [Quantifier](quantifier.md) — FOR ALL, EXISTS

## Sets

Collections of objects.

- [Set](set.md) — A collection of distinct objects
- [Element](element.md) — Membership in a set
- [Subset](subset.md) — Containment relation
- [Union](union.md) — Combining sets
- [Intersection](intersection.md) — Common elements
- [Complement](complement.md) — Elements not in a set
- [Cartesian Product](cartesian-product.md) — Pairs from two sets

## Relations and Functions

Mappings between sets.

- [Relation](relation.md) — A subset of a Cartesian product
- [Function](function.md) — A special kind of relation
- [Injection](injection.md) — One-to-one
- [Surjection](surjection.md) — Onto
- [Bijection](bijection.md) — One-to-one correspondence

## Proof Techniques

Methods for establishing truth.

- [Direct Proof](direct-proof.md) — Assume P, prove Q
- [Proof by Contradiction](proof-by-contradiction.md) — Assume NOT Q, derive contradiction
- [Proof by Contrapositive](proof-by-contrapositive.md) — Prove NOT P implies NOT Q
- [Proof by Induction](proof-by-induction.md) — Base case + inductive step
